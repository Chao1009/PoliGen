# Physics channels handled by LiPolGen — approach, references, implementing functions

LiPolGen generates doubly polarized deep-inelastic scattering of a polarized
electron beam on a polarized ⁶Li or ⁷Li ion beam (with d, ³He and p available as
control species) at EIC energies, in three fidelity tiers — **T0** (electron,
struck object and one hadronic pseudo-particle X), **T1** (the struck cluster
resolved into a struck nucleon plus on-shell partner spectators) and **T2** (the
PYTHIA 8 hadronic final state) — across five `PipelineChannel` values:
`Inclusive`, `TaggedLi6Alpha` (⁶Li(e,e′α)X, DIS on the embedded deuteron),
`TaggedLi7Alpha` (⁷Li(e,e′α)X, DIS on the quasi-free triton), `TaggedDeuteronP`
(d(e,e′p)X, the Cosyn–Weiss tagged limit used as a control) and `CoherentLi6`
(e + ⁶Li → e′ + X + ⁶Li g.s.). Almost every physics ingredient beyond the
default toy backends is **opt-in**: the exact finite-γ tensor kernel, the ANL VMC
cluster wave functions, the Ciofi degli Atti–Simula triton spectral function, the
Glauber spectator-FSI weight, the LHAPDF structure-function backends, the
polarized-EMC transfer curves and the PYTHIA hadronizer are all switched off or
replaced by a toy unless a run asks for them. This document says, per subsystem,
what is modelled, how, with what defaults and bands, on whose authority, and by
which function.

**Every symbol below is given as a repo-relative `file:line` valid at the
commit that last touched this file (`git log -1 -- docs/PHYSICS_CHANNELS.md`)
and is checked mechanically by `validation/check_physics_channels_links.py`,
which re-reads each `path:line` and fails if the named symbol is not within ±2
lines of it; `--fix` re-resolves references that code edits have shifted (last
run 2026-09-02: 826 references checked, 0 broken).** Line
ranges quoted for prose in `docs/` are not machine-checked. Where the repository
carries no citation for a number, this document says so instead of inventing one.

Every channel closes an exact four-momentum identity with one pseudo-particle X
(`Role::HadronicX`, pdg 92): the inclusive channel closes the **per-nucleon**
balance k + p_N = k′ + X; the three tagged channels close the **whole-nucleus**
balance k + P_ion = k′ + p_spec + Σp_partner + X; the coherent channel closes
k + P_ion = k′ + P_recoil + X. X is required to be timelike — a hard throw, never
a clip (`src/core/pipeline.cpp:748` `add_hadronic_x`).

## 1. Beam and target: spin density matrices, effective polarizations, beam energies

The library treats any ion beam as an incoherent mixture of |J m⟩ populations
p_m (m = +J … −J, summing to 1) along a quantization axis n(θ_S, φ_S). The
lab-frame density matrix is ρ_lab = U diag(p_m) U†, with
U_{m′m} = D^J_{m′m}(φ_S, θ_S, 0) = exp(−i m′ φ_S) d^J_{m′m}(θ_S). Observables are
traces against operators built in the same m = +J … −J ordering: the vector
polarization P = ⟨J⟩/J, the rank-2 moment (P_zz = ⟨3J_z²−2⟩ for J=1;
T = ⟨3J_z²−J(J+1)⟩/3 for J=3/2) and the rank-3 moment
O = ⟨J_z³ − (41/20) J_z⟩/(3/10), which exists only at J=3/2.

For ⁶Li the whole-nucleus effective polarization is the CLUSTER-PICTURE product
`LI6_CLUSTER_POLARIZATION` = (1 − 1.5·P_D(α–d))·(1 − 1.5·P_D(d)) =
0.86995 × 0.9325 = 0.81123, split a third each into `eff_pol_p` and `eff_pol_n`
so that Z·P_p = N·P_n = 0.81123 in g₁A = Z·P_p·g₁ᵖ + N·P_n·g₁ⁿ.

## 2. Inclusive DIS kernel: F₁/F₂/R, g₁/g₂, A∥/A⊥, the tensor sector b₁…b₄ and Δ

The unpolarized doubly-differential rate is

    d²σ/dx dQ² = (4πα²/(x Q⁴)) [ (1 − y + y²/2) F₂ − (y²/2) F_L ] ,

converted to pb by `GEV2_TO_PB`; the φ-averaged bracket every polarized term is
divided by is D_φ = F₁ + (1−y)/(x y²)·F₂. On top of it the kernel builds the
azimuthal density

    W(φ′) = 1 + w_avg + a₁ cos φ′ + a₂ cos 2φ′ ,   φ′ = φ − φ_S ,

with the vector-longitudinal term entering as
w_avg += λ_e·P_e·(m/J)·cos θ_S·A∥ (evaluated only when λ_e·P_e ≠ 0 and m ≠ 0 —
a pure projection m carries vector polarization m/J, so an m = 0 state has no
vector-L term for any spin, `src/core/xsec.cpp:265-269`), the rank-2 term as
w_avg += TENSOR_LL_SIGN·Q_NN·½(3cos²θ_S−1)·K/D_φ with K = b₁ + (1−y)/(xy²)·b₂,
and the double-helicity-flip term as
a₂ += −(1−y)/y²·c_eff·sin²θ_S·Δ/D_φ. The alignment geometry is one tensor for
any spin, t_ij = (Q_NN/2)(3n_i n_j − δ_ij) with Q_NN(m) = [3m² − J(J+1)]/3
(Cosyn Eq. 9), reducing to the HJM c_m = 3m² − 2 digit-for-digit at J = 1.

## 3. Structure-function backends: toy SFs, LHAPDF, b₁ camps, Δ models, EMC curves

Every physics input in this layer is an interface with a **toy implementation
always available** and a table/LHAPDF implementation optional. The
production defaults — `ToyF2`, `ToyG1`, `r_sigma_lt` — are explicitly
placeholders of the right magnitude, not fits, and no CLI flag or config-file key
selects any SF backend, R, EMC baseline or b₁/Δ camp. On the **Inclusive**
channel everything is injectable through the opaque `PipelineConfig::kernel`
built from `InclusiveKernel::Options`; on the **tagged** channels
`struck_cluster_kernel` exposes only `inclusive_b1` and `delta_func`, so F₂, g₁, R
and EMC there are hard-locked to `ToyF2`/`ToyG1`/`r_sigma_lt`/none.

The moment-constrained Δ solves A from A·∫ x F₁(x,Q²_ref) shape(x) dx = c_moment
(Interpretation A, default c_moment = `C_BAG` = −0.012) and then evaluates
Δ = dilution·A·α_s(Q²)·F₁·shape(x); Interpretation B drops the F₁ factor and
solves the same moment analytically through the Beta function. The shape is
x^α(1−x)^β normalized to peak 1, with variants low_x (0.3,4.0),
mid_x (0.7,3.0, the production default) and high_x (1.5,2.0).

## 4. Sampling, RNG, run-plan bookkeeping, estimators and the T0 event record

Randomness is **counter-based**, never a global stream: `Rng(seed, run, bunch,
event)` is an xoshiro256\*\* generator seeded by folding all four `uint64`
arguments through splitmix64, so every event of a (seed, run, bunch) triple gets
its own generator and a batch is bit-identical at any thread count and
independent of generation order. Three luminosity factors multiply and must never
be confused: the **programme share** (`Scenario::run_share`), the **optics
fraction** (what a de-squeezed β\*_x costs, ≈1/7–1/13 for lithium tagging) and
the **spin-state share** (`SpinCategory::lumi_fraction`, summing to one within a
plan). A share moves COUNTS, never CROSS SECTIONS.

## 5. Tagged (incoherent, spectator-tagged) channels

Each beam nucleus is modelled as a bound two-cluster system. The ion ground state
is expanded as

    |J M> = Σ_L a_L Σ_{m_L,m_S} <L m_L S_c m_S|J M> ψ̂_L(k) Y_L^{m_L}(k̂) |S_c m_S> ,

giving the joint spin ⊗ orbital amplitude
A_{m_S}(M;k,k̂) = Σ_L a_L ψ̂_L(k) C_L(M,m_S) Θ_L^{M−m_S}(cos θ_k), with the
azimuth-stripped harmonic Θ (Condon–Shortley signs) because only cos θ_k enters.
The spectator density is n_M = Σ_{m_S}|A_{m_S}|² and the struck-cluster spin
population p(m_S|M,k,k̂) = |A_{m_S}|²/n_M — a **diagonal truncation**: coherences
are dropped, and this is documented, not computed. Masses are physical
AME2020-derived nuclear masses (never A·M_u), so the k = 0 rigidity
R = (m_spec/Z_spec)/(m_beam/Z_beam) is 0.99813 for ⁶Li → α (not 1) and 0.85571
for ⁷Li → α (not 6/7), and κ = √(2μS) with μ the reduced mass of the two free
clusters and S the separation energy.

## 6. Tier T1: resolving the struck cluster into a struck nucleon plus partners

For any tagged channel at `Tier::T1` the off-shell struck cluster P_X (already
off shell because the tagged spectator was put on shell one level up) is split
into ON-SHELL partner spectators plus a struck nucleon that absorbs whatever
four-momentum is left:

    p_N,struck = P_X − Σ p_partner ,   so   p_N,struck² ≠ M_N² ,

built from the four-vectors actually emitted, so that
k + P_ion = k′ + p_spec + Σp_partner + hadrons closes exactly to rounding
whatever internal model generated the partners. This is BeAGLE's "never
recoil-correct the light spectator" rule applied a second time. **T1 is the
default on tagged channels; there is no CLI switch for the tier** — `--plan`
selects the *spin* run plan and has nothing to do with tiers — and `Tier::T0`
(the cluster left as one off-shell pseudo-particle) is kept only for
bit-compatibility with numbers published before T1 existed.

## 7. Spectator final-state interaction: a weight, never a shift

The spectator four-vector is the measurement and is never moved. Rescattering
enters only as a multiplicative weight: `weight(kin)` is the FSI/IA density ratio
(≥ 0, 1 = no distortion), `weight_normalised(kin)` divides it by its rate-weighted
mean so the SHAPE distortion is applied without changing the total rate, and
`sigma_eff_mb(W)` records the σ_XN used. `PipelineFsi::Off` — the default — is
today's plane-wave impulse approximation bit for bit. **What the pipeline
actually applies is the raw `weight()`, not `weight_normalised()`**, and
`Pipeline::sigma_pb()` is not rescaled: an FSI-on run keeps the PWIA cross
section while its event weights average to the survival probability (0.520 at
40 mb on the ⁶Li S+D tag), so the integrated tagged rate is reduced by that
factor. FSI is refused outside the three tagged channels.

At EIC energies rescattering is eikonal — it transfers only transverse momentum,
so k_z (equivalently α_s) is a spectator of the FSI. The distortion is a 2-D
convolution at fixed k_z,

    Ψ_FSI(k_z,k_T) = ψ(k_z,k_T) − ∫ d²k′_T/(2π)² G̃(k_T−k′_T) ψ(k_z,k′_T) ,

the momentum-space form of Ψ_FSI(b) = ψ(b)[1−Γ(b)] with G̃(0) = σ_Xa(1−iε)/2. It
is implemented on an (L,m) partial-wave basis, and the weight
w = Σ_{L,m}(P_L/(2L+1))\|g^FSI_{Lm}\|² / Σ_{L,m}(P_L/(2L+1))\|g_{Lm}\|² is summed
over m and averaged over the ion projection M, so the S–D interference cancels
and **the weight is spin-independent by construction** — an unpolarized-shape
systematic, never a correction to A_zz.

## 8. Coherent channel: e + ⁶Li → e′ + X + ⁶Li(g.s.)

The nucleus stays in its 1⁺ ground state and recoils with \|t\| ≈ p_T². The
header is explicit that **everything in this channel is a SCENARIO with bands, to
be replaced by a real diffractive model** — no published coherent-diffraction
calculation exists for any polarized A > 2 nucleus. The rate is carried by a
Lorentzian coherent fraction f_coh(x) = f₀/(1 + (x/x_coh)²) with f₀ = 0.04
(band 0.02–0.08) and x_coh = 0.01; the form factor is Gaussian,
\|F(t)\|² = exp(−B\|t\|) with B = R_rms²/3, default B = 50 GeV⁻² (band {40,60}).
Because the intact ⁶Li has A/Z = 2, exactly the beam rigidity, the only
far-forward handle is the Roman-Pot near-beam p_T tail, and the tag acceptance is
analytic: acc = exp(−B p_{T,cut}²), with ⟨\|t\|⟩ of the tagged sample
= p_{T,cut}² + 1/B.

The azimuthal signal is 1 + c₂ cos 2(φ_t − φ_S) with two mechanisms summed:
a t-linear **deformation** term a₂ = −(P_zz/4)·ε_B0·B·\|t\| (exact only as
\|t\| → 0; default ε_B0 = −0.08, band −(0.04…0.13), a relative slope-splitting
ΔB₀/B of the m = 0 magnetic substate) and a **flat gluon-transversity** term
amp·P_zz (default 0.01, band 3e-3…1e-2, the "exotic glue" scenario);
c₂ = 2·a₂(deformation) + amp·P_zz.

## 9. Tier T2: hadronization through a PYTHIA 8 `LHAup` bridge

PYTHIA's own hard-process machinery cannot take a per-event, Fermi-smeared
(k, p_N): with momentum spread `ProcessLevel` gates a new ECM on
`Beams:allowVariableEnergy`, which `Pythia::init` forbids for a hard process, so
the event would run at the initialisation √s; and even through an in-memory
`LHAup` at `Beams:frameType = 5` the total final-state four-momentum is forced to
the *initialisation* beam total by `BeamRemnants::setKinematics`. `BeamSetup`
additionally forces the beam on shell at its PDG mass, so a genuinely off-shell
bound nucleon is not representable directly either. The bridge therefore computes
the physical invariants q = k − k′, Q² = −q², W² = (q+p_N)² and builds a
**surrogate** e+N (or e+Pomeron) event on PYTHIA's own fixed beams matched to the
same (W², Q²):

    Ẽ′ = [P_A·k_B − B̃ + p_A Q²/(2E_B)] / (E_A + p_A) ,
    k̃_z = Q²/(2E_B) − Ẽ′ ,   k̃_T = √(Ẽ′² − k̃_z²) ,

with E_A = headroom × E_N,nominal (default headroom 1.5, a pure frame choice)
covering the ±20 % Fermi tail. Because the surrogate shares (W²,Q²) with the
physical event, mapping PYTHIA's hadronic system onto the physical one is a pure
Lorentz transformation, with a common momentum rescale λ solving
Σ√(m_i²+λ²|p_i|²) = W_want absorbing any residual mismatch. Two light-cone
fractions are kept apart: the **physical** ξ, which puts q + ξp_N on the mass
shell of the actual (moving, off-shell, or spacelike Pomeron) target,

    ξ = (Q²+m_q²) / [ (q·p_N) + √((q·p_N)² + p_N²(Q²+m_q²)) ] ,

and the **surrogate** ζ = (Q²+m_q²)/(P_A⁺ q̃⁻), which is what PYTHIA receives as
x₁; they differ only through p_N² ≠ m_A² and a dropped m_A² q̃⁺ term — sub-percent
at EIC energies.

## 10. Pipeline, output and the command line

One `Pipeline` composes the DIS sampler, the generator, the tagged and coherent
modules into the five run channels. Every event is a **pure function of its
global index** — `Rng(seed, run, category, local counter)` — so `event(i)` is
thread-safe and `for_each(sink, nthreads)` emits exactly the same events in
exactly the same order for any thread count.

## 11. Not handled (explicitly)

**Spin formalism**

- The rank-3 (octupole) moment exists only for j = 3/2 and throws for any other
  spin; `tensor_polarization` and `moments_along_axis` throw outside j ∈ {1, 3/2}.
  No general-J tensor/octupole formula is provided.
- `populations_maxent` requires strictly \|P_z\| < 1 and cannot represent a fully
  polarized fill; `rho_from_populations` throws on populations that are negative
  beyond −1e-12 or do not sum to 1 within 1e-9 — no soft renormalization.
- There is no CLI or config-file knob for the ⁷Li rank-3 moment O, and none for
  its rank-2 moment T either: from the command line T is always the
  spin-temperature value implied by `--pz` (see §1).
- **Run-plan spin vs ion spin is validated only for tagged channels.** The
  inclusive path performs no such check, so `--isotope 7Li --channel inclusive
  --plan transverse-tensor` silently runs three spin-1 categories on a ⁷Li beam.
- `beams.hpp` covers five species (p, d, ³He, ⁶Li, ⁷Li); any other name throws,
  as does `nucleus_mass` for any (name, A, Z) outside its fixed table.
- The ⟨P₂⟩ = −T/5 polarimeter identity is stated and tested only for the ⁷Li
  tagged α channel; it is neither derived nor claimed for ⁶Li or any other J.

**Inclusive kernel and structure functions**

- The exact finite-γ tensor kernel is **off by default**: the O(γ²) rate-sector
  leakage into cos 2φ (Δ_fake/(γ²b₁) ≈ 0.14–0.16) is carried as a systematic of
  the Δ extraction, never subtracted automatically, and depends on the unmeasured
  b₃/b₄ slots.
- Δ (gluonometry) keeps its massless kinematic factor even on the `tensor_gamma`
  path — it is outside Cosyn's b₁–b₄ basis and is given no finite-γ treatment.
- A⊥ is never switched on by the pipeline (`with_perp` is false on both the
  inclusive and the tagged path, and no CLI or config-file key exposes it); when
  it is on it uses the massless ε(y) and D(y) irrespective of `target_mass`.
- The finite-γ kinematics use the FREE nucleon mass, never
  `Ion::mass_per_nucleon`; the bound mass would move γ² by ≈1 % of an already
  ≤10 % correction.
- No CLI flag exposes `target_mass`, `tensor_gamma`, `g2_mode` or `g2_scale`;
  they are set only through `Options` in code, tests or scripts.
- Rank-2 structure is gated to ion spin 1 or 3/2: `tables()` fills b₁/b₂/Δ for
  those two spins alone and the rank-2 branch runs only when both the kernel's
  and the state's spin are ≥ 1; below spin 1 the whole tensor and Δ sector is
  exactly zero. b₃/b₄ are filled for every spin but read only on the
  `tensor_gamma` path.
- The polarized medium ratio (`cbt_`/`tmt_polarized_emc_ratio`) is **not
  reachable from event generation at all**: no kernel passes a `medium_ratio` to
  `g1_nucleus` and `Options` has no polarized-medium slot. Likewise the
  unpolarized `emc_ratio` hook is empty in every default kernel, so F₂A carries
  no medium modification anywhere.
- On the tagged channels the struck-cluster kernel is hard-locked to
  `ToyF2`/`ToyG1`/`r_sigma_lt`/no EMC: only `inclusive_b1` and `delta_func` are
  exposed. Nothing selects the b₁ camp, the b₁ mode, the Δ interpretation, the
  Δ variant/dilution/α_s, the R backend or the EMC baseline from the CLI.
- No published ⁶Li b₁ measurement exists; the `Li6B1` embedded-deuteron rank-2
  transfer is explicitly an inference, and whether Δ should carry an analogous
  rank-2 transfer (rather than the flat 1/3 dilution) is open.
- The Close–Kumano sum rule ∫b₁ dx = 0 is **reported, not enforced**, and only
  over the digitized range of the raw per-deuteron column.
- Both polarized-EMC curves are for nuclei other than the target and need a
  valence-scale transfer whose baseline is a stated CHOICE, not a computed fact.
- `LhapdfG1` (NNPDFpol1.1) carries three flavours only; Δc = Δb = 0 is the PDF
  set's own convention and cannot be turned on here. The production α_s
  convention (the CT18NLO table) has no C++ equivalent in the core library.
- LHAPDF-backed backends require the optional LHAPDF build, and the nuclear
  F₂A/g₁A combinations are not duplicated for them — a caller must wrap them in
  the existing `NuclearF2` / `g1_nucleus`.

**Sampling and estimators**

- Modulation amplitudes are evaluated only at (x,Q²) **cell centres** — adequate
  for binned Phase-1 estimators by construction, not for unbinned in-cell shapes.
- `cos2phi_moment` is valid for uniform acceptance only; the binned fit requires
  uniform bins and a C(1 + A cos 2φ′) shape (a residual cos φ′ term is orthogonal
  only at full coverage) and needs ≥ 3 live bins after the acceptance probe.
- The (A−1) nuclear remnant is deliberately **not** written at T0's per-nucleon
  balance; the tagged tier owns it, and that is what turns the per-nucleon
  balance into a whole-nucleus one.
- The 25 mrad crossing angle is a LAB transform applied downstream, never inside
  the T0 assembly.
- The polarimetry-scale systematic `delta_p_over_p` has no CLI option; every CLI
  run carries measured ≡ true polarizations. `--rel-lumi-offset` is silently
  ignored by the single-category transverse-tensor plan.

**Tagged channels and breakup**

- Coherences between struck-cluster spin states are dropped: p(m_S\|M,k,k̂) is a
  DIAGONAL truncation of the density matrix.
- No partial wave beyond L = 2 is supported anywhere (`theta_lm` and the analytic
  radial switch both throw).
- VMC tables return exactly 0 outside their tabulated k range (no extrapolation),
  and sign information above ≈3 fm⁻¹ is deliberately ignored (Monte-Carlo noise
  floor).
- The deuteron control channel is **always Hulthén** — a wiring choice, not a
  data gap: `deuteron_channel` takes no `ClusterWaveSource` and the pipeline pins
  P_D = 0.045, although `data/vmc/deuteron/fdeut.av18` carries the exact AV18
  deuteron u(k)/w(k) in the very form the VMC reader consumes (it is used only to
  validate the Fourier–Bessel convention).
- Under `--cluster-wave vmc` the tagged α–d D-state probability becomes 0.0193
  while the **inclusive** effective polarization keeps 0.0867 — in that mode the
  two genuinely differ. Independently, `--p-d` never reaches `LI6().eff_pol`.
- ³H → p + nn is explicitly not modelled as a VMC overlap: it is a genuine
  three-body breakup, and no such spectroscopic-overlap file exists at the source.
- Neither triton branch has any D-wave/tensor structure (both isotropic in the
  relative direction); the spectral-function branch factorizes S_N(k,E) into n(k)
  times a k-independent pair excitation density, which a real Faddeev/AV18
  S(k,E) would not. The CS parameterization gives no minority-nucleon (struck
  proton) distribution at all — the isoscalar approximation used instead is
  acknowledged to be wrong in the isovector regime.
- `cluster_species()` throws for any (Z,A) outside nucleon, deuteron and triton;
  no other cluster species is handled.
- The α_s light-front variable is the MINUS fraction, with the opposite k_z sign
  to the Strikman–Weiss/Cosyn–Weiss convention (§5) — an open bookkeeping item.
- The struck-cluster off-shell / spectator-on-shell split is a **choice**, not a
  derived result, and FSI never modifies it.

**FSI**

- FSI is restricted to the three tagged channels; `validate()` throws for
  `Inclusive` and `CoherentLi6`.
- The principal-value (off-shell) piece of the longitudinal rescattering integral
  is dropped, not computed.
- The weight is spin-independent by construction: the model carries **no spin
  dependence of the rescattering**, which the cited reference lists as an open
  question. Quote it as an unpolarized-shape systematic, never as a correction to
  A_zz.
- `GlauberNucleon` is not a true correlated per-nucleon product: the
  centre-of-mass constraint Σ_i s_i = 0 and short-range NN correlations in the
  cluster density are an explicit open TODO.
- The formation ramp is unreachable from `cli.py`/`PipelineConfig` (only the
  single fixed σ_XN row is), as are ε, B_XN, `elastic_gain` and every grid field.
- `cluster_point_a2_fm2` recognizes a fixed table of clusters and throws
  otherwise; `φ_k` is carried but unused (the eikonal kernel is azimuthally
  symmetric).

**Coherent channel**

- Everything here is a SCENARIO with bands, "to be replaced by a real diffractive
  model"; no published calculation exists for any polarized A > 2 nucleus. The
  deformation term is scaled — with a sign flip — from a deuteron CGC
  calculation, and the flat term from bounds the repo does not cite.
- The M_X < 1.2 GeV window (ρ/ω/φ exclusive vector-meson production) carries no
  rate at all: it is a separate process deferred to Phase 2.
- `coherent_t_max`, `coherent_xpom` and `coherent_weighted_azimuth` have no CLI
  or config-file key; `x_coh` and ε_B0 are reachable only through the config
  file's `coherent` mapping, whose keys are the FIELD NAMES `x_coh` and
  `eps_b0` (§8).
- `--coherent-t2`, `--pom-set` and `--pom-rescale` are silently ignored without
  `--hadronize`.

**T2 hadronization**

- Lepton QED radiation is off (`PDF:lepton`, `TimeShower:QEDshowerByL`,
  `SpaceShower:QEDshowerByQ`); PYTHIA's own documentation states that QED
  radiation off the lepton is not implemented together with `dipoleRecoil`, so
  this is a PYTHIA limitation as well as a choice. Radiative corrections are a
  separate work package.
- No nuclear effects on the hadronic final state: no shadowing, no EMC
  modification of fragmentation, no nuclear transparency, no FSI moving any
  produced hadron, no formation-time physics. Nuclear PDFs are not used because
  PYTHIA's are hard-process-only and give an average nucleon — the opposite of
  what a tagged generator needs.
- The remnant of an off-shell nucleon is built from an **on-shell PDG-mass
  surrogate**: the off-shellness enters W²/Q² exactly, but the remnant's internal
  composition, primordial k_T and diquark mass are those of a free nucleon.
- Spin in the hard process is helicity-averaged; SPINUP is carried through the
  LHA record and consumed by nothing. MPI is absent by construction with a lepton
  beam. Charm and bottom are always massless, collinear INCOMING partons.
- Heavy flavours are never produced on the Pomeron flavour-fallback branch (the
  H1 LO grids have no charm/bottom support at any (β,Q²)); `Diffraction:doHard`
  is not usable, so the id-990 beam is a workaround, not that mechanism.
- The `StruckCluster` hook is DEPRECATED and unreachable from a `Pipeline` at the
  default tier; taking it anyway does not conserve the whole record.
- `CoherentT2::Off` leaves coherent events at T0 with no hadron-level final state.
- The `abconv` → `npsim` → EICrecon smoke test is not run from this repository;
  the HepMC3 spin attributes are a proposed convention, not an ePIC-MC-group
  standard, and `abconv`/`npsim` do not carry event attributes through to edm4hep.

**Output and CLI**

- Only HepMC3 Asciiv3 is implemented; `HepMC2Ascii` throws.
- `--lumi` alone is rejected (see §10); `--hfs-npz` requires `--hadronize`;
  `--hadronize` forces `--nthreads 1`.
- A tagged or coherent channel IMPLIES its beam species: `PipelineConfig::validate`
  throws on a mismatch, and `make_config` silently overrides the `--isotope`
  argument with the channel's own species, so `--isotope d --channel coherent`
  runs ⁶Li (§10). Only the *run-plan spin* vs ion spin check is skipped on the
  inclusive path (above); the species rule holds everywhere.
- T2 runs only when `PipelineConfig::hadronizer` is set: the tier is a hook, not
  a flag, and nothing but `--hadronize` (or a C++/Python caller) fills it.
- The four C++ example generators (`generate_inclusive`, `generate_tagged`,
  `generate_coherent`, `generate_full`) are **not** `lipolgen-run`: their flag
  spellings differ (`--slope`, `--f0`, `--eps-b0`, `--tmax`, `--pd`, `--beta`,
  `--threads`, `--out`), they take no config file and no `--hepmc`/`--npz`
  (§10, `docs/USAGE.md:548-556`).
- `tier`, `poisson`, `n_sigma`, `pot_config`, `with_virtual_photon`,
  `apply_optics_lumi_fraction`, `scenario` and `grid` are `make_config` keyword
  arguments only, and `kernel`, `breakup`, `struck.delta_func`/`with_perp` only
  attributes of a `PipelineConfig` object — none of them has a command-line
  switch. `struck.scenario` and `struck.grid` are attributes too, but DEAD on
  the pipeline path: the constructor overwrites both with
  `PipelineConfig::scenario`/`grid` (§10).
